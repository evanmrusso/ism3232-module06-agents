## My Assistant: Grass Dragon FAQ Assistant

Kc is an FAQ assistant for Grass Dragon, a made-up volleyball equipment store, that answers customer questions about store hours, holiday hours, locations, returns, shipping, and payment. It is a mock: its replies come from keyword rules and a fixed dictionary of answers in my_main.py, not from an AI model or a real store database, and it only treats a message as a question if it contains a question mark. Requests about refunds, damaged items, or a customer's own order are passed to a store employee, because the assistant has no access to any customer's order information and cannot decide whether an item was damaged or give money back. If a question has no matching keyword, it says it does not have that answer and lists what it can help with instead of making one up. If this assistant used real customer data, its history would store every message exactly as typed, so a customer who sent their card number, address, or order details would have that private information saved in plain text where others could see it.
